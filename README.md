## Featured Projects

### Retail Demand Forecasting with MLOps
Built an end-to-end ML system that predicts future retail product demand using historical sales data.  
Includes preprocessing, feature engineering, LightGBM modeling, MLflow experiment tracking, FastAPI prediction service, Docker, and PostgreSQL storage.

### AI Job Match & Resume Analyzer
Developed an AI-powered application that compares a resume against a target job description and generates a structured job-fit analysis.  
The system highlights matched skills, missing skills, improvement areas, and an overall match score.

### PostgreSQL-Based Image Retrieval with pgvector
Designed a content-based image retrieval system using ResNet-50 embeddings, PostgreSQL, pgvector, and HNSW indexing.  
The project searches images by visual similarity instead of file names or manual tags.

### Churn Prediction with Explainability
Built a customer churn prediction pipeline with model explainability to identify why customers may leave.  
Focused on clean preprocessing, model evaluation, feature importance, and business-friendly interpretation.

### Maze Solving with Reinforcement Learning
Implemented reinforcement learning algorithms for maze-solving environments, including Q-learning, SARSA, Monte Carlo, and Dynamic Programming approaches.
